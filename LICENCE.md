**Cinder City Hack Menu** is a curated list of Cinder City open-source tools:

- **Quality-of-Life Helpers** — loot tracker, HUD notes, config manager

## ✨ Features

### ESP
- Radar Overlay — track nearby entities and points of interest
- Loot Tracker — log item spawns and locations
- Map Overlay — display minimap and waypoints
- Speed Control — adjust movement speed for study (0.1x to 5x)

### Wallhack
- Skin Browser — preview outfits and colors
- HUD Customizer — rearrange and resize UI elements
- Theme Manager — switch overlay color schemes

### Aimbot
- Practice Mode Notes — segment study on any layout
- Free Camera — detach camera for exploration
- Teleport Notes — record and review key locations
